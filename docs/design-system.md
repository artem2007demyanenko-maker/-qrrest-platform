# QRRest Design System

## Style

- premium dark SaaS
- restaurant-tech aesthetic
- iiko + Stripe + Linear inspired
- glassmorphism light
- deep navy backgrounds
- soft gradients
- rounded 20px cards
- subtle glow
- thin borders
- modern dashboard feel

## Rules

- avoid bootstrap appearance
- avoid generic admin panels
- avoid flat white cards
- focus on hierarchy
- large typography
- clean spacing
- premium metrics cards
- realtime feeling UI

## Animations

- smooth hover transitions
- soft pulse animations
- subtle motion only
- no aggressive animations

## Frontend

- vanilla JS preferred
- modular CSS
- responsive layout
- reusable components

## UX

- fast restaurant workflow
- minimal clicks
- large action buttons
- important statuses highlighted
- kitchen/table flows must be readable instantly

## Inspirations

- Stripe Dashboard
- Linear
- Vercel
- Toast POS
- iiko Front
- modern POS systems
