# QRRest Roadmap

## Current stable baseline

Проверяемые сценарии (должны оставаться рабочими на каждом этапе):

- QR-меню открывается
- корзина работает
- заказ создаётся
- заказ виден персоналу
- статусы заказа меняются
- loyalty / поиск гостя работает
- тестовые staff-аккаунты доступны
